## Exact route

Use the existing blind 24-candidate decomposition on the reduced target kernel.
All geometry policies use the same exact empty-aggregate-range certificate and
the same bounded original root DP. If unresolved, the new route uses that one
selected projection, without receiving planted base, outliers or family label.

Rank items by decreasing absolute residual, ties by original kernel index.
Try deleting the first $d=0,1,\ldots,9$ ranked items; retain the first partition
whose full reusable table satisfies the declared area/history/work gates.
Use target-truncated $Q$ valid for ALL shifted targets, as proved in
[theory](THEORY.md). Build one signed two-coordinate DP, retain prefix rows,
then query all necessary Gray-code exceptional assignments. Include exact
indexed witness reconstruction. A complete failed enumeration certifies NO;
any interrupted phase returns unresolved. Table construction is never repeated
per assignment. Data-only discovery may fail to find an available good core.

Caps: $HW\le2{,}000{,}000$, logical prefix history at most $64{,}000{,}000$ bits,
at most nine exceptions. Core execution receives at most 60,000 work units
and three quarters of currently remaining work, preserving fallback allowance.
Discovery rechecks this remaining-work gate for each candidate. A conservative
work bound includes table allocation, every row update, every prefix-history
reference copied, exceptional updates/point queries, and witness work.
Charge discovery including residual ranking/partition scans before using results.
Actual bit widths/object overhead are measured by live time, not assumed uniform.

## Matched controls

Five policies: `lean` skips geometry; `root` uses original root geometry only;
`discover_only` adds new partition discovery to root but does not execute the
new core; `reuse` adds full reusable-core solving; `direct_mitm` skips geometry
and directs its fallback allowance to MITM. All first pay exact target reduction,
the same original 15-input acquisition and all five existing zero-deletion core
queries. No doubling or classifier costs are needed for these exact policies.
Root checking keeps its 12,000-work limit, at most four admissible q values,
and existing area/history bounds.

Shared fallback: bitset, memoized DFS, MITM. Divide remaining work and remaining
live time among remaining methods, carrying unused allowance forward. Existing
32,768-state and one-million-bit ordinary-bitset caps remain. Every policy uses
the same implementations, reduction/index lifting and returned-witness checks.
Discovery-only isolates new acquisition overhead; direct MITM is an additional
strong solver control. No learned or approximate decision ever certifies NO.
