# Latin Modern web fonts

These WOFF2 files are conversions of the Latin Modern OpenType fonts shipped
with MiKTeX. They let the site use the same font family as the papers' PDFs:
Latin Modern Roman for body text and Latin Modern Sans for titles and headings.

Source: [Latin Modern](https://www.gust.org.pl/projects/e-foundry/latin-modern)
by GUST. License: [GUST-FONT-LICENSE.txt](GUST-FONT-LICENSE.txt).

To regenerate after installing `fonttools[woff]`, run `python fonts/build_fonts.py`.
